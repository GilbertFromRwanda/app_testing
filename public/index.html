Askfor Test Runner

Configure, run, and inspect k6 load tests

Configuration

Traffic profile

Rotates the real TCP source IP per connection. Used by both the k6 and Go outputs (the Go program binds each connection via net.Dialer.LocalAddr). Only works if the machine (or container, via network_mode: host / macvlan) actually owns these addresses — configure them as NIC aliases first (Windows: New-NetIPAddress; Linux: ip addr add). Leave blank to send from the default IP.

Thresholds
Think time between iterations (s)
Authentication

Runs once per virtual user before its first request. k6 keeps a per-VU cookie jar, so a PHP session cookie (e.g. PHPSESSID) set by this call is automatically resent on every later request — just like a browser. If the login response also returns a JSON token, fill in the token field below to attach it as a header on every request too.

Extra headers (sent on every request)

Spreads traffic across IP-keyed rate limiters (e.g. NestJS ThrottlerGuard) so a per-IP limit isn't hit during the test, and blends the load in with normal browser traffic. The IP part only works if the target is behind a reverse proxy it trusts and derives the client IP from these headers (Express/NestJS with trust proxy enabled). It does not change the real network-level source IP. Each request is also tagged with its IP so the Results tab can break traffic down per client.

Requests (executed in order, each iteration)

The Go output runs in the separate go-runner container. Send to go-runner writes the program to ./generated, its watcher runs it with go run, and the output streams back to the Live log tab here (the Stop button aborts it). The run ends with a ==== SUMMARY ==== block in that log instead of the k6 charts. Or hit Download to run it by hand: go run <file>.go (Go 1.21+, stdlib-only, no modules). It rotates the real TCP source IP via net.Dialer.LocalAddr, so set Source IPs to addresses this host actually owns (or the literal auto for every address already on its NIC). Addresses that aren't locally assigned are checked and skipped before the run, not failed per request.
