Authentication

Runs once per virtual user before its first request. k6 keeps a per-VU cookie jar, so a PHP session cookie (e.g. PHPSESSID) set by this call is automatically resent on every later request — just like a browser. If the login response also returns a JSON token, fill in the token field below to attach it as a header on every request too.

Extra headers (sent on every request)
